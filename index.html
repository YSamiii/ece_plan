阳光黄主题手绘小狐狸18–26月龄
🌼 执行规则
每天完成当日基础启蒙；如该月龄已录入“早教课”，则在周一、周三、周五、周六加入打卡。每个月龄计划只在周一切换，保证同一周从周一到周日完整执行。当天状态一般时，可以缩短每项时间，但不取消语文、数学或英语中的任何一类。
🐾 宝宝资料
📒 月龄计算说明
系统按完整月龄计算。例如，从出生日期到今天满18个月但未满19个月，显示为18月龄。目前已加入18—26月龄计划，系统会根据宝宝完整月龄自动切换到对应计划。
📦 计划更新
以后新增月龄或补充课程详情时，只需更新课程库 JSON，不需要重新安装 App。你可以从 GitHub 自动检查更新，也可以手动导入文件；宝宝资料和打卡记录不会被覆盖。
☁️
从 GitHub 检查课程库
把最新版课程库上传到仓库的 data/curriculum.json，并把相关图片放进 data/assets/。以后你和朋友只需点这里，不需要重新安装 App。
🦊
手动上传课程更新包
支持 .json 文件；如果课程里带图片，请同时把 GitHub 上的 data/assets/ 文件夹一起更新。
